Simulación 1D de una onda generada por un ultrasonido en un medio heterogéneo

Este repositorio contiene un script en Python diseñado para simular la propagación de un pulso ultrasónico unidimensional a través de dos medios biológicos distintos: tejido blando y hueso craneal. 
El modelo se resuelve numéricamente utilizando el método de diferencias finitas.

El código requiere Python 3 y las siguientes librerías:
* `numpy` para los arreglos y cálculos matriciales.
* `matplotlib` para la visualización de los resultados.
